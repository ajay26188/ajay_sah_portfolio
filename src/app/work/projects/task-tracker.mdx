## Overview

**TaskTracker** is a modern, full-stack project management app designed for teams to **collaborate, assign tasks, and track progress in real time**.  
The app emphasizes **clean architecture, and production-grade workflows**, including role-based access, modular APIs, real-time updates, and automated deployments.

Currently, both backend and frontend are fully integrated and deployed (~190 hours logged).  
Development follows a **company-like workflow** with a public log available in the [TaskTracker GitHub Repository](https://github.com/ajay26188/task_tracker).

## 🔧 Features

### 🔑 Authentication & Authorization
- JWT-based authentication  
- Role-based UI and access control  
- Email verification flow  
- Password reset via secure token  

### 🏢 Organizations
- Data isolation at the organization level  
- Admins manage projects and teams independently  

### 📂 Projects & Tasks
- Create, update, and assign tasks  
- Query-based filtering (`GET /api/tasks?projectId=...`)  
- Pagination for large task sets  

### 🗂️ Kanban Board
- **Drag & Drop Tasks** across **To Do**, **In Progress**, and **Done**  
- Optimistic UI updates with backend sync and rollback safety  
- Smooth animations with **Framer Motion**  
- Assignee avatars (initials) on tasks  
- Real-time updates across all team members via **Socket.IO**

### 💬 Real-Time Collaboration
- **Notifications**:  
  - Instant alerts when tasks are assigned/updated  
  - Bell icon with unread badge + history pagination  
  - Mark single/all as read  

- **Comments on Tasks**:  
  - Real-time chat-like experience with auto-scroll and highlights  

### ⚙️ Backend (Node.js + Express + MongoDB + Mongoose)
- Auth system with JWT + role-based middleware  
- Zod validation schemas for all endpoints  
- Task APIs with filtering and pagination  
- Notification system with personalized messages  
- Email verification and password reset (Brevo + Nodemailer)  
- Database seeding for realistic demo data  
- Centralized error handling with JSON responses  

---

## 🛠️ Tech Stack

- **Frontend:** React + TypeScript, Redux Toolkit, Framer Motion  
- **Backend:** Node.js, Express, MongoDB, Mongoose  
- **Real-Time:** Socket.IO (notifications, comments, Kanban updates)  
- **Validation:** Zod  
- **Auth:** JWT with role-based middleware  
- **Email Service:** Nodemailer + Brevo  
- **CI/CD:** GitHub Actions → Render (backend), Vercel (frontend)  
- **Dev Tools:** ESLint, TypeScript, Nodemon  

---

## 📚 Challenges & Learnings

- Balancing API flexibility with consistent contracts  
- Enforcing **organization-based isolation** early for scalability  
- Efficient **task pagination** for large datasets  
- Using **Zod schemas** to enforce strict validation and reduce runtime errors  
- Designing **CI/CD pipelines** to simulate team workflows  
- Debugging Vercel cold start issues with uptime strategies  
- Switching SMTP → Brevo HTTPS integration to maintain free-tier compatibility
